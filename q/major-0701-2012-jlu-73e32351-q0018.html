设 f(x) 在 [0,1] 上连续可微，证明 limn→∞ | n∫₀¹ f(x)dx − ∑k=1n f(k/n) | ≤ supx∈[0,1] |f′(x)|

答案（证明思路提纲，非完整证明）
**要证**：把 n∫₀¹f dx 拆成 n 个小区间上的矩形(右端点)和，证 n∫₀¹f dx − ∑f(k/n) 的极限存在且等于 (f(0)−f(1))/2，从而绝对值不超过 sup|f′|（实际 ≤ ½sup|f′|）。\n\n**用到的定理/引理**：\n- 积分可加性 + 右端点矩形公式误差的逐块改写：n∫₀¹f dx − ∑_{k=1}^n f(k/n) = ∑_{k=1}^n n∫_{(k-1)/n}^{k/n}[f(x)−f(k/n)]dx\n- 拉格朗日中值定理（或一阶泰勒展开）：f(x)−f(k/n) = f′(ξ)(x−k/n)\n- 连续函数的模 of continuity：因 f′ 连续故一致连续，|f(x)−f(k/n)−f′(k/n)(x−k/n)| ≤ ω(|x−k/n|) ≤ ω(1/n)，ω(0+)=0\n- f′ 连续 ⇒ 黎曼和收敛：(1/n)∑_{k=1}^n f′(k/n) → ∫₀¹f′ dx\n- 牛顿–莱布尼茨公式 ∫₀¹f′ = f(1)−f(0)，以及 |f(1)−f(0)| ≤ sup|f′|\n\n**证明思路**：\n1. 分块：n∫₀¹f dx − ∑f(k/n) = ∑_{k=1}^n n∫_{(k-1)/n}^{k/n}[f(x)−f(k/n)]dx（每块长 1/n）。\n2. 块内展开：f(x)−f(k/n) = f′(k/n)(x−k/n) + r_k(x)，其中 |r_k(x)| ≤ ω(1/n)，ω 为 f′ 的一致连续模。\n3. 逐项积分主部：n∫_{(k-1)/n}^{k/n}(x−k/n)dx = −1/(2n)，故主部合计 = −(1/2)·(1/n)∑f′(k/n)；余项合计绝对值 ≤ (1/2)ω(1/n) → 0。\n4. 令 n→∞，由 f′ 连续得 (1/n)∑f′(k/n) → ∫₀¹f′ = f(1)−f(0)，所以极限存在且 lim = (f(0)−f(1))/2（即 −½(f(1)−f(0))）。\n5. 取绝对值：|lim| = |f(1)−f(0)|/2 ≤ ½sup|f′| ≤ sup|f′|，结论成立（常数 ½ 已是锐利，f(x)=x 时取等）。\n6. 备用捷径（只证上界、不追问存在性）：第 2 步直接用 |f(x)−f(k/n)| ≤ M(k/n−x)，积分得每块 ≤ M/(2n)，求和得对一切 n 有 |·| ≤ M/2。\n\n**易错点**：\n- 题干写 lim 而非 limsup：单靠第 6 步的一致界推不出极限存在，必须先证第 4 步的极限 = (f(0)−f(1))/2，或明确按 limsup 处理。\n- 别误以为误差是 o(1)：右端点矩形公式误差是 1/n 阶，乘 n 后不趋于 0（f(x)=x 时恒为 −1/2），所以不能用『黎曼和收敛 ⇒ 差趋于 0』草率收尾。\n- 余项控制要用 f′ 的一致连续性（题设『连续可微』= C¹）；只用逐点中值定理 ξ 依赖 x 且 ξ 不定，写不出一致的 o(1/n)。\n\n**不确定**：此型题常见表述是 lim = (f(0)−f(1))/2 或上界写成 ½sup|f′|；按所给 sup|f′| 亦成立但非最优，若原卷常数为 ½ 则第 4 步已直接给出。另假定「连续可微」指 f′ 在 [0,1] 连续。
