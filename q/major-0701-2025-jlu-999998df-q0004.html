2025 · 空间解析几何和高等代数 · 四1 | 证明 |20 分

设 V 是 n 维欧氏空间，n ≥ 2，σ 是 V 的对称变换，记 $L = \{\tau \text{ 是 } V \text{ 的线性变换} \mid \sigma\tau = \tau\sigma\}.$ 证明：dim L = n 当且仅当 σ 的每个特征子空间都是一维的.
查看答案与解析
答案（证明思路提纲，非完整证明）
**要证**：dim L = Σ n_i²（n_i 为 σ 的各特征子空间维数），因此 dim L = n 当且仅当每个 n_i = 1，即每个特征子空间一维\n\n**用到的定理/引理**：\n- 对称变换（实自伴算子）的谱定理：σ 可正交对角化，V 是互异特征值对应特征子空间的正交直和\n- 在按特征子空间分块的正交基下，σ = diag(λ₁I_{n₁}, …, λ_kI_{n_k})，可换条件 στ = τσ 逐块化为 (λ_i − λ_j)T_{ij} = 0\n- 分块矩阵维数计算：dim End(V_{λ_i}) = n_i²，故 dim L = Σ n_i²\n- 不等式 n_i² ≥ n_i（n_i ≥ 1），且 Σ n_i = n，等号当且仅当各 n_i = 1\n\n**证明思路**：\n1. 由 σ 对称，取谱定理得 V = V_{λ₁} ⊕⊥ … ⊕ V_{λ_k}，记 n_i = dim V_{λ_i}，Σ n_i = n；在此正交分块基下 σ = diag(λ₁I_{n₁}, …, λ_kI_{n_k})。\n2. 把任意 τ 按同一分块写成 τ = (T_{ij})，其中 T_{ij} 为 n_i×n_j 块。\n3. 由 στ = τσ 得逐块条件 (λ_i − λ_j)T_{ij} = 0；因 λ_i ≠ λ_j (i ≠ j)，故非对角块全为 0，τ 必为分块对角 diag(T₁₁, …, T_kk)。\n4. 反之任取分块对角的 τ 显然与 σ 可换，于是 L ≅ End(V_{λ₁}) ⊕ … ⊕ End(V_{λ_k})，得 dim L = Σ_{i=1}^{k} n_i²。\n5. 由 n_i ≥ 1 且 n_i² ≥ n_i（等号当且仅当 n_i = 1），有 Σ n_i² ≥ Σ n_i = n，等号成立当且仅当每个 n_i = 1。\n6. 合并 4、5 即得 dim L = n ⟺ 每个特征子空间都是一维，双向皆成立。\n\n**易错点**：\n- 第 3~4 步的 dim L = Σ n_i² 依赖 σ 可对角化（即题设“对称”），若不加说明直接套公式，逻辑不完整：必须先确认正交分块基存在且特征子空间张成 V\n- 非对角块为零用的是 λ_i ≠ λ_j，务必先声明 λ₁,…,λ_k 是全部互异特征值，分块只按不同特征值划分\n- “⟸”方向要指出：若每个特征子空间一维，则 k = n（σ 恰有 n 个互异特征值），且不要把非特征值处的 0 维核 {0} 误计入“特征子空间”\n\n**不确定**：无（默认“特征子空间”指对应实际特征值 V_λ = ker(σ−λI) 且 λ 跑遍全部互异特征值）
