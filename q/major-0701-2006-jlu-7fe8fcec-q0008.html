设 A 为实对称矩阵，证明，必有实对称矩阵 B，使得 A + B 为正定矩阵.
查看答案与解析
答案（证明思路提纲，非完整证明）
**要证**：可显式构造 B = tI（t 为大于 −λ_min(A) 的正实数），它实对称，且 A + B = A + tI 的特征值全为正，故正定。\n\n**用到的定理/引理**：\n- 实对称矩阵的谱定理（正交对角化）：A = QΛQᵀ，Λ = diag(λ₁,…,λₙ)，λᵢ∈ℝ\n- 正定判定：实对称矩阵正定 ⟺ 所有特征值 > 0（等价于 ∀x≠0, xᵀSx > 0）\n- 特征值平移不变性：spec(A + tI) = {λᵢ + t}\n- Rayleigh 商下界估计：xᵀAx ≥ λ_min‖x‖²\n\n**证明思路**：\n1. 设 A 的特征值为 λ₁ ≤ … ≤ λₙ（均为实数，来自谱定理），记 λ_min = λ₁，它可能为负。\n2. 取实数 t 满足 t > −λ_min（等价地 t > max(0, −λ_min)，如取 t = 1 + ‖A‖₂ 即可保证）。\n3. 令 B = tI，则 Bᵀ = B，B 为实对称矩阵，存在性已被显式构造出来。\n4. 由 A = QΛQᵀ 得 A + B = Q(Λ + tI)Qᵀ，其特征值为 λᵢ + t > 0（i = 1,…,n）。\n5. 实对称 + 特征值全正 ⟹ A + B 正定，证毕。\n6. 备用一步到位的二次型写法：∀x≠0，xᵀ(A + tI)x = xᵀAx + t‖x‖² ≥ (t + λ_min)‖x‖² > 0。\n\n**易错点**：\n- t 的取值必须给出依赖 λ_min 的严格下界，不能只写“取 t 充分大”这种模糊说法（且要 >，不能 ≥，否则只得半正定）。\n- 若改用另一种构造 B = tI − A（使 A + B = tI），需先说明 B 对称是由 A 对称推出的，且 t 只需 > 0；两种路线别混着用导致特征值论证失效。\n- “特征值全正 ⟺ 正定”这一等价只在实对称（Hermitian）前提下成立，引用前要点明 A + tI 仍是对称的；改用顺序主子式论证会明显变繁，不建议。\n\n**不确定**：按题面直译，这是一个几乎一行的存在性命题（B = tI 即解决），作为 2006 年试卷第五题第 1 问偏易，原题很可能对 B 另有附加约束（如要求 B 半正定、幂等、与 A 可交换、给定秩或迹、或同时要求 A − B 也正定等）。若有此类条件，上述构造需按约束重做（例如再加“B 幂等”就一般不成立或需改用谱分解分块构造）。此处按所给题面作答。
