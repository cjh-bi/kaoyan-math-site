2011 · 空间解析几何和高等代数 · 41 | 证明 |15 分

设 β 是 n 元非齐次线性方程组 AX = b 的一个解向量，α₁, …, αₙ 是响应的齐次线性方程组 AX = 0 的一个基础解系. 证明：β, β + α₁, β + α₁ + α₂, …, β + α₁ + … + αₙ 是 AX = b 的一组线性无关解.
查看答案与解析
答案（证明思路提纲，非完整证明）
**要证**：要证 β, β+α₁, β+α₁+α₂, …, β+α₁+…+αₙ₋₁ 既都是 AX=b 的解，又线性无关。\n\n**用到的定理/引理**：\n- 非齐次解的结构：特解+齐次解仍是非齐次解（A(β+Σα)=b+0=b）\n- 基础解系定义：α₁,…,αₙ₋₁ 线性无关且张成 AX=0 的解空间\n- b≠0（非齐次）⇒ β 不是 AX=0 的解，用系数矩阵 A 作用等式两边可分离出 β 的系数\n- 线性无关的定义法；等价的矩阵法：向量组右乘可逆矩阵不改变线性相关性\n\n**证明思路**：\n1. 记 γ₀=β，γₖ=β+α₁+…+αₖ（k=1,…,n−1）。先证「是解」：$A\gamma_k = A\beta + A\alpha_1+\dots+A\alpha_k = b+0 = b$。\n2. 辅助结论：β, α₁,…,αₙ₋₁ 线性无关。设 $c_0\beta + c_1\alpha_1+\dots+c_{n-1}\alpha_{n-1}=0$，两边左乘 A 得 $c_0 b=0$；由 $b\neq 0$ 得 $c_0=0$，再据基础解系的线性无关性得 $c_1=\dots=c_{n-1}=0$。\n3. 设 $k_0\gamma_0+k_1\gamma_1+\dots+k_{n-1}\gamma_{n-1}=0$，按 β 与 αᵢ 归并系数：$(k_0+k_1+\dots+k_{n-1})\beta + (k_1+\dots+k_{n-1})\alpha_1 + \dots + k_{n-1}\alpha_{n-1}=0$。\n4. 由第 2 步令每个系数为 0，得倒三角形方程组 $c_j = k_j+\dots+k_{n-1}=0$；从 $k_{n-1}=0$ 逐次回推，得 $k_0=k_1=\dots=k_{n-1}=0$，故线性无关。\n5. 合并第 1 步与第 4 步即完成证明。\n（矩阵法备选：$(\gamma_0,\dots,\gamma_{n-1}) = (\beta,\alpha_1,\dots,\alpha_{n-1})\,C$，$C$ 为上三角且对角元全为 1，$\det C = 1 \neq 0$，由第 2 步的无关性直接得第 4 步结论。）\n\n**易错点**：\n- 题设要求证两件事：「都是解」和「线性无关」，只写后者会丢分\n- 第 2 步中 $c_0=0$ 必须依赖 $b\neq0$（即 β 不属于导出组解空间），这一步是核心得分点，不能默认\n- 归并系数后是倒三角结构，回推顺序要写清楚，否则会误判为「方程不够」\n\n**不确定**：题干「α₁,…,αₙ 是基础解系」应为 α₁,…,αₙ₋₁：n 元方程组的导出组基础解系若含 n 个向量，则 r(A)=0，且待证组是 n+1 个 n 维向量，必然线性相关，命题不成立。2011 年该题通行版本为 r(A)=1、基础解系含 n−1 个向量，上面按 n−1 个作答。
