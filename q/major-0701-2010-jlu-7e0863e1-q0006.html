2010 · 空间解析几何和高等代数 · 61 | 证明 |20 分

设 A, B 都是 n 阶矩阵，并且每个 n 元列 β 或是方程组 Ax = 0 的解，或是方程组 Bx = 0 的解. 证明 A = 0 或 B = 0.
查看答案与解析
答案证明：设 $N(A),N(B)$ 分别为 $Ax=0$ 与 $Bx=0$ 的解空间，题设即 $F^n=N(A)\cup N(B)$。 反设 $A\neq 0$ 且 $B\neq 0$，则 $N(A),N(B)$ 都是 $F^n$ 的真子空间。取 $u\notin N(A)$，则 $u\in N(B)$；取 $v\notin N(B)$，则 $v\in N(A)$。考虑 $u+v$：若 $u+v\in N(A)$，则 $u=(u+v)-v\in N(A)$，矛盾；若 $u+v\in N(B)$，则 $v=(u+v)-u\in N(B)$，矛盾。故假设不成立。 所以 $N(A)=F^n$ 或 $N(B)=F^n$，即 $\boxed{A=0 \text{ 或 } B=0}$
1. 记 $N(A)=\{\beta\in F^n\mid A\beta=0\}$，$N(B)$ 同理，二者都是 $F^n$ 的子空间；题设“每个 $n$ 元列 $\beta$ 或是 $Ax=0$ 的解或是 $Bx=0$ 的解”即 $F^n=N(A)\cup N(B)$。\n2. 反设 $A\neq 0$ 且 $B\neq 0$。注意 $N(A)=F^n\iff A=0$（$A$ 的每一列为零），故由反设得 $N(A)\subsetneq F^n$，$N(B)\subsetneq F^n$，都是真子空间。\n3. 由真包含可取 $u\notin N(A)$，而 $u\in F^n=N(A)\cup N(B)$，必有 $u\in N(B)$；同法取 $v\notin N(B)$，必有 $v\in N(A)$。\n4. 考察 $w=u+v\in F^n$，由并集条件 $w\in N(A)\cup N(B)$，即 $w$ 至少属于其一。\n5. 若 $w\in N(A)$：因 $v\in N(A)$ 且 $N(A)$ 对减法封闭，$u=w-v\in N(A)$，与 $u\notin N(A)$ 矛盾；若 $w\in N(B)$：因 $u\in N(B)$，$v=w-u\in N(B)$，与 $v\notin N(B)$ 矛盾。两分支同时封死。\n6. 故反设不成立，$N(A)=F^n$ 或 $N(B)=F^n$，等价于 $A=0$ 或 $B=0$。（本质原理：域上的线性空间不能表为两个真子空间的并；本证明只用加法封闭性，不依赖 $F$ 无限。）
