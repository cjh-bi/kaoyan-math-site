2012 · 数学分析 · 32 | 证明

设 f 是闭区间 [a,b] 上光滑函数. 且对 [a,b] 中任意两点 x₁ < x₂，都惟一存在一点 ξ ∈ (x₁,x₂) 使得 [f(x₂) − f(x₁)]/(x₂ − x₁) = f′(ξ). 证明：在 [a,b] 上 f 要么是凸函数，要么是凹函数
查看答案与解析
答案（证明思路提纲，非完整证明）
**要证**：由差商所对应的中值点唯一，推出 g = f′ 在 [a,b] 上单调（严格），故 f 整体为凸或整体为凹。\n\n**用到的定理/引理**：\n- 拉格朗日中值定理（差商即 f′ 在 [x₁,x₂] 上的平均值 avg）\n- 连续函数介值定理 + 最值定理：min f′ < avg < max f′（非常值时严格）\n- 连续函数超水平集 {f′ > c} 是开集，取含峰点的连通分支 (r,s)，则 f′(r) = f′(s) = c 且内部 f′ > c\n- 单调性的三点判据：若一切 x < y < z 都有 g(y) 介于 g(x) 与 g(z) 之间，则 g 单调\n- 凸凹判定：f′ 单调递增 ⇔ f 为凸；f′ 单调递减 ⇔ f 为凹（光滑时即 f″ ≥ 0 或 f″ ≤ 0）\n\n**证明思路**：\n1) 记 g = f′，题设等价于：对任意 x₁ < x₂，方程 g(ξ) = avg(g; x₁, x₂) := (f(x₂) − f(x₁))/(x₂ − x₁) 在 (x₁, x₂) 内恰有一个解。\n2) 排除常值段：若 g 在某个非退化子区间恒等于 k（哪怕贴着 a 或 b），则该区间上的差商恰为 k，每一点都满足方程，与唯一性矛盾；于是对任意 x₁ < x₂ 有严格不等式 min g < avg < max g（在 [x₁,x₂] 上取）。\n3) 反证「无峰」：设存在 x < y < z 使 g(y) > max(g(x), g(z))，取 c 满足 max(g(x),g(z)) < c < g(y)，在 (x,z) 内取含峰点的连通分支 (r,s) 使 g > c 于 (r,s)、g(r) = g(s) = c，记 c′ ∈ (r,s) 为 g 在 [r,s] 的最大点。\n4) 对区间 [r,s] 用第 2 步：c < avg(r,s) < g(c′)，由介值性 avg(r,s) 在 (r,c′) 与 (c′,s) 各被 g 取到一次，得到两个不同中值点，与唯一性矛盾；「无谷」完全同理。\n5) 故对一切 x < y < z，g(y) 总介于 g(x) 与 g(z) 之间，由三点判据知 f′ 单调；再用第 2 步排除常值段，得 f′ 严格单调。\n6) f′ 递增 ⇒ f 是凸函数；f′ 递减 ⇒ f 是凹函数；二者必居其一，证毕。\n\n**易错点**：\n- 唯一性本身不直接否定 f′ 不单调，必须先单独处理「f′ 在某区间恒为常数」（含端点邻域）这一退化情形，否则第 2 步的严格不等式不成立\n- 第 4 步里 avg(r,s) > c 用到 g > c 且连续（积分严格更大），avg(r,s) < g(c′) 用到 g 不恒等于最大值，这两处不等式要写明，不能只说「介于之间」\n- 不要去对 ξ(x₁,x₂) 用隐函数定理求导：中值点的选择未必唯一连续、也未必可导；本题只依赖中值定理 + 介值性\n\n**不确定**：「光滑」按 f ∈ C∞、即 f′ 连续理解（否则第 3–4 步的介值性论证要改走达布定理，且水平集分支端点存在性需另证）。凸/凹按非严格定义（允许线性函数既算凸又算凹）；若要求严格凸凹，则结论应改为「f′ 严格单调但不排除 f 为线性」，题干未区分。
