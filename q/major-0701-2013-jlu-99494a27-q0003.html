2013 · 空间解析几何和高等代数 · 13 | 计算 |10 分

用 Gramer 规则求解线性方程组 { 2x₁ + x₂ − 5x₃ + x₄ = 8 ; x₁ − 3x₂ − 6x₄ = 9 ; 2x₂ − x₃ + 2x₄ = −5 ; x₁ + 4x₂ − 7x₃ + 6x₄ = 0 }
查看答案与解析
答案$x_1 = 3,\ x_2 = -4,\ x_3 = -1,\ x_4 = 1$
1) 写出系数行列式并按第一列展开：$D=\begin{vmatrix}2&1&-5&1\\1&-3&0&-6\\0&2&-1&2\\1&4&-7&6\end{vmatrix}=2\cdot36-1\cdot18-1\cdot27=72-18-27=27\neq0$，故方程组有唯一解，可用 Cramer 法则。\n2) 把常数列 $(8,9,-5,0)^{T}$ 依次替换 $D$ 的第 1、2、3、4 列，得到 $D_1,D_2,D_3,D_4$。\n3) $D_1=\begin{vmatrix}8&1&-5&1\\9&-3&0&-6\\-5&2&-1&2\\0&4&-7&6\end{vmatrix}=8\cdot36-9\cdot18-5\cdot9=288-162-45=81$。\n4) 其余三个先作行变换消去第一列（$r_1-2r_2$、$r_4-r_2$）再展开，例如 $D_2=-\begin{vmatrix}-10&-5&13\\-5&-1&2\\-9&-7&12\end{vmatrix}=-108$；同法得 $D_3=-\begin{vmatrix}7&-10&13\\2&-5&2\\7&-9&12\end{vmatrix}=-27$，$D_4=-\begin{vmatrix}7&-5&-10\\2&-1&-5\\7&-7&-9\end{vmatrix}=27$。\n5) 由 $x_i=D_i/D$：$x_1=81/27=3$，$x_2=-108/27=-4$，$x_3=-27/27=-1$，$x_4=27/27=1$。\n6) 回代检验：$2(3)-4+5+1=8$；$3+12-6=9$；$-8+1+2=-5$；$3-16+7+6=0$，四个方程全部成立。
