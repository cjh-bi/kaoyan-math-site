2010 · 空间解析几何和高等代数 · 51 | 计算 |20 分

已知 A, B, C 都是 n 阶矩阵，A 可逆，并且 CB = CAⁱB = 0, i = 1,2,…,n. 证明 (A B ; C A) 可逆，并求其逆.
查看答案与解析
答案(A B; C A) 可逆，且 (A B; C A)⁻¹ = [ A⁻¹ + A⁻¹BA⁻¹CA⁻¹ , −A⁻¹BA⁻¹ ; −A⁻¹CA⁻¹ , A⁻¹ ]（分块矩阵）
1) 由 Cayley–Hamilton，$A^{-1}$ 是 $I,A,\dots,A^{n-1}$ 的线性组合（常数项 $a_0=(-1)^n\det A\neq0$），故条件 $CA^{i}B=0\ (i=0,1,\dots,n)$ 蕴含 $CA^{-1}B=0$。\n2) 分块分解：$\begin{pmatrix}A&B\\C&A\end{pmatrix}=\begin{pmatrix}A&0\\C&I\end{pmatrix}\begin{pmatrix}I&A^{-1}B\\0&A-CA^{-1}B\end{pmatrix}=\begin{pmatrix}A&0\\C&I\end{pmatrix}\begin{pmatrix}I&A^{-1}B\\0&A\end{pmatrix}$，两个因子都可逆（Schur 补 $A-CA^{-1}B=A$），故原矩阵可逆。\n3) 逆为 $\begin{pmatrix}I&-A^{-1}BA^{-1}\\0&A^{-1}\end{pmatrix}\begin{pmatrix}A^{-1}&0\\-CA^{-1}&I\end{pmatrix}=\begin{pmatrix}A^{-1}+A^{-1}BA^{-1}CA^{-1}&-A^{-1}BA^{-1}\\-A^{-1}CA^{-1}&A^{-1}\end{pmatrix}$。\n4) 验证：乘回去时用 $CA^{-1}B=0$（从而 $A^{-1}CA^{-1}B=0$）即得单位阵。
