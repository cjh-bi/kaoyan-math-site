2010 · 空间解析几何和高等代数 · 81 | 证明 |15 分|2 个小问

设 V 是 n 维欧式空间，L 是 V 的所有线性变换构成的向量空间，𝒜 是 V 的对称变换，k₁, …, kₛ 是 𝒜 的所有特征子空间的维数. 令 C = {ℬ ∈ L | 𝒜ℬ = ℬ𝒜}. 证明
(1) C 是 L 的子空间
(2) dim C = k₁² + … + kₛ²
查看答案与解析
答案（证明思路提纲，非完整证明）
**要证**：与对称变换 𝒜 可交换的线性变换全体 C 是 L 的子空间，且 dim C 等于 𝒜 各（互异特征值对应的）特征子空间维数的平方和，即 $\dim C=\sum_{i=1}^{s}k_i^2$\n\n**用到的定理/引理**：\n- 自伴（实对称）变换的谱定理：𝒜 有 $s$ 个互异实特征值 $\lambda_1,\dots,\lambda_s$，$V=V_1\perp\cdots\perp V_s$，$\dim V_i=k_i$，$\sum k_i=n$\n- 子空间判定：非空 + 对线性组合封闭\n- 关键等价：$\mathcal{A}\mathcal{B}=\mathcal{B}\mathcal{A}\iff \mathcal{B}$ 把每个特征子空间 $V_i$ 不变（$\mathcal{B}(V_i)\subseteq V_i$）\n- 取各 $V_i$ 的正交规范基拼成 $V$ 的基，$\mathcal{A}$ 化为分块对角形 $\mathrm{diag}(\lambda_1 I_{k_1},\dots,\lambda_s I_{k_s})$，比较矩阵块\n- 线性同构 $C\cong\bigoplus_{i=1}^{s}\mathrm{End}(V_i)\cong\bigoplus_{i=1}^{s}M_{k_i}(\mathbb{R})$，$\dim\mathrm{End}(V_i)=k_i^2$\n\n**证明思路**：\n1. 证 (1)：$0\in C$；若 $\mathcal{B}_1,\mathcal{B}_2\in C$，则 $\mathcal{A}(\alpha\mathcal{B}_1+\beta\mathcal{B}_2)=(\alpha\mathcal{B}_1+\beta\mathcal{B}_2)\mathcal{A}$，故 $C$ 是 $L$ 的子空间。\n2. 用谱定理写出 $\mathcal{A}$ 的互异特征值 $\lambda_1,\dots,\lambda_s$ 与特征子空间 $V_i$，说明 $V$ 是它们的直和（这一步是「对称」条件的全部作用：保证实特征值 + 可对角化），$\dim V_i=k_i$。\n3. 证明方向「$\mathcal{B}\in C\Rightarrow \mathcal{B}(V_i)\subseteq V_i$」：对 $v\in V_i$ 有 $\mathcal{A}(\mathcal{B}v)=\mathcal{B}(\mathcal{A}v)=\lambda_i(\mathcal{B}v)$，故 $\mathcal{B}v$ 仍属 $\lambda_i$ 的特征子空间。\n4. 证明反向「$\mathcal{B}$ 保持每个 $V_i$ 不变 $\Rightarrow \mathcal{A}\mathcal{B}=\mathcal{B}\mathcal{A}$」：在每个 $V_i$ 上 $\mathcal{A}=\lambda_i I$，于是 $\mathcal{A}\mathcal{B}|_{V_i}=\lambda_i\mathcal{B}|_{V_i}=\mathcal{B}\mathcal{A}|_{V_i}$，由 $V=\sum V_i$ 得整体交换。\n5. 在上述基下设 $\mathcal{B}$ 的块矩阵为 $(B_{ij})$（$B_{ij}$ 为 $k_i\times k_j$），交换条件给出 $(\lambda_i-\lambda_j)B_{ij}=0$；$i\neq j$ 时 $\lambda_i\neq\lambda_j$，故 $B_{ij}=0$，即 $\mathcal{B}$ 必为块对角 $\mathrm{diag}(B_{11},\dots,B_{ss})$，而对角块 $B_{ii}$ 无任何额外约束。\n6. 于是 $\mathcal{B}\mapsto(B_{11},\dots,B_{ss})$ 是 $C$ 到 $\bigoplus_i M_{k_i}(\mathbb{R})$ 的线性双射，得 $\dim C=\sum_{i=1}^{s}k_i^2$。\n\n**易错点**：\n- 不能只对「可对角化」默认成立：必须先说明 $\mathcal{A}$ 对称（自伴）$\Rightarrow$ 特征值全为实数且 $V$ 分解为特征子空间的直和；若换成一般的实矩阵（有复特征值或亏损），$\sum k_i<n$，结论不成立。\n- 「$\mathcal{B}\in C\Rightarrow V_i$ 不变」与「$V_i$ 不变 $\Rightarrow\mathcal{B}\in C$」两个方向都要写，只写一个不能建立等价，计数就没有依据。\n- 块 $B_{ii}$ 是任意 $k_i\times k_i$ 方阵，贡献 $k_i^2$，别误当成对称块写成 $k_i(k_i+1)/2$；$k_1,\dots,k_s$ 是按互异特征值排列的维数，不是重数的重复计数。\n\n**不确定**：无（按标准约定：$k_1,\dots,k_s$ 是 $\mathcal{A}$ 对应于 $s$ 个互异特征值的特征子空间维数，故 $\sum k_i=n$）
