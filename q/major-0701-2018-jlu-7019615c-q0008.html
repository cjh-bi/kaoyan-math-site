2018 · 空间解析几何和高等代数 · 81 | 计算 |10 分

求证：在直角坐标系下，二次曲面 (ax + by + cz + d)(Ax + By + Cz + 1) = 0, (a ≠ 0) 的标准方程为 z′² − (1/4)·(aD − dA)²/[A²(a² + b² + c²)] = 0 或 y′² − [√(a²+b²+c²)√(A²+B²+C²) − (aA + bB + cC)]/[√(a²+b²+c²)√(A²+B²+C²) + (aA + bB + cC)]·x′² = 0.
查看答案与解析
答案**命题成立。** 该曲面即两平面 $ax+by+cz+d=0$ 与 $Ax+By+Cz+1=0$ 的并： - 当两法向量平行（$A\neq 0$）时，标准方程为 $$z'^2-\frac{(a-dA)^2}{4A^2(a^2+b^2+c^2)}=0$$ （两平面重合时退化为 $z'^2=0$）； - 当两法向量不平行时，两平面相交，标准方程为 $$y'^2-\frac{\sqrt{a^2+b^2+c^2}\sqrt{A^2+B^2+C^2}-(aA+bB+cC)}{\sqrt{a^2+b^2+c^2}\sqrt{A^2+B^2+C^2}+(aA+bB+cC)}\,x'^2=0,$$ 其中系数即 $\tan^2\frac{\theta}{2}=\dfrac{1-\cos\theta}{1+\cos\theta}$，$\theta$ 为两平面夹角
**第 1 步（分解）** 曲面 $(ax+by+cz+d)(Ax+By+Cz+1)=0$ 是两平面的并：$\pi_1: \boldsymbol n\cdot\boldsymbol x+d=0$，$\boldsymbol n=(a,b,c)$；$\pi_2: \boldsymbol N\cdot\boldsymbol x+1=0$，$\boldsymbol N=(A,B,C)$。$a\neq0$ 保证 $\pi_1$ 不退化。按 $\boldsymbol N\parallel\boldsymbol n$ 与否分两种情形。\n\n**第 2 步（平行情形）** 设 $\boldsymbol N=\lambda\boldsymbol n$，由 $a\neq0$ 得 $\lambda=A/a$，故必有 $A\neq0$；$\pi_2$ 化为 $\boldsymbol n\cdot\boldsymbol x+a/A=0$。两平面间距 $h=\dfrac{|d-a/A|}{\|\boldsymbol n\|}=\dfrac{|dA-a|}{|A|\sqrt{a^2+b^2+c^2}}$。\n\n**第 3 步（平行情形的标准方程）** 取 $z'$ 轴沿 $\boldsymbol n$、原点平移至两平面正中点，则 $\pi_1,\pi_2$ 变为 $z'=\pm h/2$，乘积方程 $(z'-h/2)(z'+h/2)=0$，即 $z'^2-\dfrac{(dA-a)^2}{4A^2(a^2+b^2+c^2)}=0$（$x',y'$ 自由）。当 $dA=a$ 时 $h=0$，两面重合退化为 $z'^2=0$。\n\n**第 4 步（相交情形）** $\boldsymbol N$ 与 $\boldsymbol n$ 不平行时两面交于一直线，取交线为 $z'$ 轴；在与交线垂直的平面内两平面截为过原点的两条直线，其夹角 $\theta$ 满足 $\cos\theta=\dfrac{\boldsymbol n\cdot\boldsymbol N}{\|\boldsymbol n\|\|\boldsymbol N\|}=\dfrac{aA+bB+cC}{\sqrt{a^2+b^2+c^2}\sqrt{A^2+B^2+C^2}}$。\n\n**第 5 步（相交情形的标准方程）** 在该垂直平面内取两条角平分线为 $x'$ 轴与 $y'$ 轴，两直线即 $y'=\pm\tan\dfrac{\theta}{2}\,x'$，乘积给出 $y'^2-\tan^2\dfrac{\theta}{2}\,x'^2=0$，且 $\tan^2\dfrac{\theta}{2}=\dfrac{1-\cos\theta}{1+\cos\theta}=\dfrac{\sqrt{a^2+b^2+c^2}\sqrt{A^2+B^2+C^2}-(aA+bB+cC)}{\sqrt{a^2+b^2+c^2}\sqrt{A^2+B^2+C^2}+(aA+bB+cC)}$，即题给系数（$z'$ 不出现，为秩 2 的退化二次曲面）。\n\n⚠️ 该步存疑：题干第 3 步的分子写作 $(aD-dA)^2$，但原方程中并无字母 $D$；按 $\pi_1$ 的常数项 $d$ 与 $\pi_2$ 的系数 $A$ 严格计算得 $(dA-a)^2$，与最终答案所用形式一致，题干应为笔误。
