设 f(x) 在 [1, +∞) 上有定义，且存在正的常数 l, L，对任意的 x₁, x₂ ∈ [1, +∞)，都有 $l|x₂ − x₁| ≤ |f(x₂) − f(x₁)| ≤ L|x₂ − x₁|.$ 证明存在 X ∈ [1, +∞)，使得 (x + e^{−x})/f(x) 在 [X, +∞) 上一致连续.
查看答案与解析
答案（证明思路提纲，非完整证明）
**要证**：取 X 足够大后可使 |f(x)| ≥ (l/2)x，于是 (x+e^{−x})/f(x) 在 [X,+∞) 上满足 Lipschitz 估计 |h(x)−h(y)| ≤ M|x−y|，从而一致连续。\n\n**用到的定理/引理**：\n- 下界取基点 x=1：|f(x)| ≥ |f(x)−f(1)|−|f(1)| ≥ l(x−1)−|f(1)|（故 f 最终不变号且 1/|f(x)| = O(1/x)）\n- 分子记 φ(x)=x+e^{−x}：由 e^{−x} 单调且 |e^{−x}|′ ≤ 1 得 |φ(x)−φ(y)| ≤ 2|x−y|，且 x ≥ 1 时 φ(x) ≤ 2x\n- 分式作差恒等式 h(x)−h(y)=\dfrac{φ(x)−φ(y)}{f(x)}+φ(y)\dfrac{f(y)−f(x)}{f(x)f(y)}\n- 上界 |f(y)−f(x)| ≤ L|x−y|（同时给出 f 连续）\n- Lipschitz（乃至导数有界）⇒ 一致连续；备选：连续 + 在 +∞ 处极限存在 ⇒ 一致连续\n\n**证明思路**：\n1. 由 |f(x)| ≥ l(x−1)−|f(1)|，取 X ≥ max{1, 2+2|f(1)|/l}，则 x ≥ X 时 |f(x)| ≥ (l/2)x ≥ (l/2)X > 0，即 \left|1/f(x)\right| ≤ 2/(lX)。\n2. 令 h(x)=(x+e^{−x})/f(x)，任取 x,y ≥ X，用作差恒等式拆成两项 T_1+T_2。\n3. 放大 T_1：|T_1| ≤ 2|x−y|·2/(lX) = 4|x−y|/(lX)。\n4. 放大 T_2：|T_2| ≤ 2y·L|x−y|\big/\left(\tfrac{l}{2}x\cdot\tfrac{l}{2}y\right) = 8L|x−y|/(l^2 x) ≤ 8L|x−y|/(l^2 X)（关键是分子里的 y 被下界中的 f(y) 约掉，于是右端与 x,y 无关）。\n5. 合并得 |h(x)−h(y)| ≤ M|x−y|，M=4/(lX)+8L/(l^2 X)<∞，故 h 在 [X,+∞) 上 Lipschitz，从而一致连续，证毕。\n6. （等价的替代写法）拆 h = x/f(x) + e^{−x}/f(x)：前者按第 3–5 步证 Lipschitz，后者满足 0 ≤ |e^{−x}/f(x)| ≤ 2e^{−x}/(lX) → 0，由「连续 + ∞ 处极限存在 ⇒ 一致连续」处理。\n\n**易错点**：\n- 不能默认 f(x)≠0 或 f 无界：必须先用下界（在 x=1 处取值）证明 |f(x)| 线性增长——这正是题目要「存在 X」而非「在 [1,∞) 上」的原因。\n- 不要声称 x/f(x) 或 h(x) 在 +∞ 处有极限：让 f 的斜率在 l 与 L 之间于越来越长的区间上交替，即可使 f(x)/x 无极限，故「有极限⇒一致连续」这条捷径对 h 本身不成立。\n- Lipschitz 常数 M 含 1/X，直接取 X=1 时估计未必失效但写法上必须保证 (l/2)x ≤ |f(x)| 成立；作差时若只用单侧下界会留下含 x 的因子，必须两侧同时使用才能消去。\n\n**不确定**：题干中 e^{−x} 我按 exp(−x)（→0）理解；若原卷为 e^{x}，则分子不再是低阶项，第 4 步中 φ(y) ≤ 2y 的估计失效，结论一般不成立。
