设 u = u(x,y), v = v(x,y) 是由方程组 { 3x = 3ev + u³ ; 3y = 3eu + v³ } 确定的隐函数，其中 eu+v ≠ u²v²，求 ∂u/∂x、∂u/∂y、∂v/∂x、∂v/∂y
查看答案与解析
答案∂u/∂x = -v²/(e^{u+v}-u²v²)，∂u/∂y = e^v/(e^{u+v}-u²v²)，∂v/∂x = e^u/(e^{u+v}-u²v²)，∂v/∂y = -u²/(e^{u+v}-u²v²)
两式分别对 $x,y$ 求偏导（除以 3）得 $u^2 u_x+e^v v_x=1,\ e^u u_x+v^2 v_x=0$ 及 $u^2 u_y+e^v v_y=0,\ e^u u_y+v^2 v_y=1$。系数行列式 $\Delta=u^2v^2-e^{u+v}=-(e^{u+v}-u^2v^2)\neq0$。用 Cramer 法则解得 $u_x=v^2/\Delta=-v^2/(e^{u+v}-u^2v^2),\ v_x=-e^u/\Delta=e^u/(e^{u+v}-u^2v^2),\ u_y=-e^v/\Delta=e^v/(e^{u+v}-u^2v^2),\ v_y=u^2/\Delta=-u^2/(e^{u+v}-u^2v^2)$。
