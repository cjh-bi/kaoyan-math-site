2012 · 空间解析几何和高等代数 · 52 | 证明

设 B = (1 2 3 ; 0 1 4 ; 0 0 1)，A 与 B¹⁰ 相似，求 r(A − 2I) + r(A − I)
查看答案与解析
答案（证明思路提纲，非完整证明）
**要证**：求 $r(A-2I)+r(A-I)$，利用相似不变量把 $A$ 换成 $B^{10}$，最终结果为 $3+2=5$。\n\n**用到的定理/引理**：\n- $B=I+N$ 分解 + 二项式展开 $(I+N)^{10}=I+10N+\binom{10}{2}N^2$（$N$ 幂零，$N^3=0$）\n- 相似不变量：若 $A\sim C$，则 $A-\lambda I=S^{-1}(C-\lambda I)S$，故 $r(A-\lambda I)=r(C-\lambda I)$\n- $r(M-\lambda I)$ 与特征值的关系：$\lambda$ 非特征值 $\iff M-\lambda I$ 可逆（满秩）\n- 上三角矩阵特征值即对角元，秩由非零行数读出\n\n**证明思路**：\n1. 令 $N=B-I=\begin{pmatrix}0&2&3\\0&0&4\\0&0&0\end{pmatrix}$，验证 $N^2=\begin{pmatrix}0&0&8\\0&0&0\\0&0&0\end{pmatrix}\ne0$，$N^3=0$。\n2. 由二项式定理：$B^{10}=I+10N+45N^2=\begin{pmatrix}1&20&390\\0&1&40\\0&0&1\end{pmatrix}$（$30+360=390$）。\n3. $B^{10}$ 为上三角，特征值全为 $1$，故 $A$ 的特征值也全为 $1$，$2$ 不是特征值 $\Rightarrow A-2I$ 可逆 $\Rightarrow r(A-2I)=3$。\n4. $r(A-I)=r(B^{10}-I)=r(10N+45N^2)=r\begin{pmatrix}0&20&390\\0&0&40\\0&0&0\end{pmatrix}=2$。\n5. 相加得 $r(A-2I)+r(A-I)=3+2=5$。\n\n**易错点**：\n- 别把 $r(A-I)$ 当成特征值 $1$ 的几何重数：几何重数是 $3-r(A-I)$，这里是 $1$，不要反过来写 $r=1$。\n- $B^{10}$ 不要硬乘，也不要漏掉 $45N^2$ 项；漏了会误判 $r(B^{10}-I)=1$。\n- $r(A-2I)=3$ 依赖「$A$ 的特征值全为 $1$」这一步，必须先说明相似保持特征值，不能凭直觉。
