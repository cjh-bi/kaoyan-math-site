设 f(x) = { x, x ≥ 0 ; sin x, x < 0 }，求不定积分 ∫ f(x)dx
查看答案与解析
答案∫f(x)dx = { x²/2 + C, x ≥ 0 ; 1 − cos x + C, x < 0 }（C 为同一任意常数）
1. $x\ge0$：$\int x\,dx=\frac{x^2}{2}+C_1$；$x<0$：$\int\sin x\,dx=-\cos x+C_2$。\n2. 原函数必连续，在 $x=0$ 处 $\frac{0^2}{2}+C_1=-\cos 0+C_2$，得 $C_1=C_2-1$。\n3. 取 $C_1=C$，$C_2=C+1$，则 $x<0$ 段为 $1-\cos x+C$（该段在 $0^-$ 处极限为 $C$，与右段连续）。\n4. 验证：$F'_+(0)=0=F'_-(0)=f(0)$，故 $F$ 在 $\mathbb{R}$ 上可导且 $F'=f$。
