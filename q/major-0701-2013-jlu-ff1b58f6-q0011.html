2013 · 数学分析 · 41 | 证明 |20 分

记 D = {(x,y) : 0 < x < 1, 0 < y < 1}，并设函数 f(x,y) = ax² + 2bxy + cy² + dx + ey，其中 a,b,c,d,e 是常数. 证明：若在 ∂D（表示 D 的边界）上有 f(x,y) ≤ 0 成立，则对任意 (x,y) ∈ D 都有 f(x,y) ≤ 0.
查看答案与解析
答案（证明思路提纲，非完整证明）
**要证**：设 f 在闭方块的四条边 ∂D 上非正，则 f 在整个 D（实际上整个 ¯D）上非正；关键是把"若有内点取正值，则最大值点必为内点"转化为 Hessian 半负定。\n\n**用到的定理/引理**：\n- Weierstrass 定理：f 连续，在紧集 ¯D=[0,1]² 上取最大值\n- 内点极值的必要条件：∇f(P₀)=0 且 Hessian H=[[a,b],[b,c]] 半负定 ⇒ a≤0, c≤0, ac≥b²\n- 二次型非正的配方：a,c≤0 且 ac≥b² ⇒ ax²+2bxy+cy²≤-(√(-a)x-√(-c)y)²≤0\n- 沿边的一元二次不等式取极限（x→0⁺）读出一次项符号：d≤0, e≤0\n- 反证法\n\n**证明思路**：\n1. 反证：假设存在 P₁∈D 使 f(P₁)>0；f 在 ¯D 上连续，设最大值 f(P₀)=M>0，由 ∂D 上 f≤0 知 P₀=(x₀,y₀) 是 ¯D 的内点。\n2. 内点极大给出 ∇f(P₀)=0，且二阶必要条件 H=[[a,b],[b,c]] 半负定，故 a≤0、c≤0、ac≥b²（注意 H 为常矩阵，与 P₀ 无关）。\n3. 于是二次型 Q(x,y)=ax²+2bxy+cy² 对一切 (x,y)∈R² 非正：配方 Q≤-(√(-a)x-√(-c)y)²≤0（a=0 或 c=0 时由 ac≥b² 得 b=0，结论同样成立）。\n4. 用边的信息定一次项：在 y=0 上 f(x,0)=ax²+dx=x(ax+d)≤0 对 x∈(0,1] 成立，除以 x 令 x→0⁺ 得 d≤0；同理在 x=0 上 f(0,y)=cy²+ey≤0 得 e≤0。\n5. 合并：对任意 x≥0, y≥0 有 f(x,y)=Q(x,y)+dx+ey≤0，与 f(P₁)>0 矛盾，故 D 上 f≤0（连边一起，¯D 上 f≤0）。\n6. 收尾一句：等号在 (0,0) 处成立（f(0,0)=0），说明结论不能再加强。\n\n**易错点**：\n- ∇f=0 与 Hessian 半负定只能用于内点：必须先有 M>0 与"边界 f≤0"才能断定最大值点是内点；否则要改用 KKT/边界讨论。\n\n- 由 ax²+dx≤0 直接写"a≤0 且 d≤0"是不严谨的（例如 a=1,d=-2 也成立）；d≤0 只能由 x→0⁺ 的极限得到，a≤0 则来自 Hessian 半负定，两条来源别混。\n\n- 第 3 步的配方默认 a<0,c<0；退化情形 a=0（或 c=0）要单独说明 b=0，再回到 Q=cy²≤0。\n\n**不确定**：把 ∂D 理解为闭方块的四条边（含四个角点）；若题意只在两条过原点的边 {y=0}∪{x=0} 上给 f≤0，则第 1 步"最大值点是内点"不成立，结论也不成立（需另加条件）。其余无疑问。
