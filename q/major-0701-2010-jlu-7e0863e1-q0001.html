直线 { x + y + z = 0 ; y + z + 1 = 0 } 和 { x + z + 1 = 0 ; x + y + 1 = 0 } 是否共面？说明理由.
查看答案与解析
答案不共面（两直线为异面直线）
1. $L_1$ 方向 $\vec d_1=(1,1,1)\times(0,1,1)=(0,-1,1)$，取点 $P_1(1,0,-1)$；$L_2$ 方向 $\vec d_2=(1,0,1)\times(1,1,0)=(-1,1,1)$，取点 $P_2(-1,0,0)$。\n2. $\vec d_1$ 与 $\vec d_2$ 不成比例，故两直线不平行，只可能相交或异面。\n3. 混合积 $(\vec d_1\times\vec d_2)\cdot\overrightarrow{P_1P_2}=(-2,-1,-1)\cdot(-2,0,1)=4-1=3\neq 0$。\n4. 混合积非零，两直线异面，所以不共面。
