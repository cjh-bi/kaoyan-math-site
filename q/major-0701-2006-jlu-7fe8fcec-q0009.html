2006 · 空间解析几何和高等代数 · 六1 | 证明 |17 分

设 V 为数域 Ω 上的 2n 维向量空间，σ 为 V 上的线性变换，且 Ker σ = σ(V). 证明，存在 V 的一个适当基底及 Jordan 形矩阵 A，使得 σ 在该基底下恰好对应矩阵 A.
查看答案与解析
答案（证明思路提纲，非完整证明）
**要证**：σ 是幂零指数为 2 的幂零变换，在适当基底下其矩阵唯一确定为 A = diag(J₂(0), …, J₂(0))，即 n 个「超对角线为 1」的二阶 Jordan 块，J₂(0) = [0 1; 0 0]。\n\n**用到的定理/引理**：\n- 维数公式（秩–零化度定理）：dim ker σ + dim σ(V) = dim V = 2n\n- Im σ = Ker σ ⇒ σ² = 0，从而最小多项式 m(x) | x²，Jordan 标准形存在（特征值全为 0，在 Ω 内已分裂），且块的大小 ≤ 2\n- Jordan 块个数 = dim ker σ（特征值 0 的几何重数），配合总维数定出块的大小分布\n- 原像提升构造基：对 η ∈ Im σ 取 ξ 使 σ(ξ) = η，用「两边作用 σ」证明线性无关\n- 同域上的矩阵相似的 Jordan 形唯一性（保证分块顺序无关，A 形状确定）\n\n**证明思路**：\n1. 由 Ker σ = σ(V) 与维数公式得 dim Ker σ = dim σ(V) = n。\n2. 任取 α ∈ V，有 σ(α) ∈ σ(V) = Ker σ，故 σ²(α) = 0，即 σ² = 0；于是 σ 幂零，m(x) | x²，全部特征值为 0，Jordan 形存在且每个块不超过二阶。\n3. 设二阶块 p 个、一阶块 q 个，由「块数 = dim Ker σ = n」得 p + q = n，由维数得 2p + q = 2n，解出 p = n, q = 0，故目标形为 A = diag(J₂(0), …, J₂(0))。\n4. 构造基：取 Ker σ（= σ(V)）的一组基 η₁, …, ηₙ；因 ηᵢ ∈ σ(V)，可取 ξᵢ ∈ V 使 σ(ξᵢ) = ηᵢ。\n5. 验证 η₁, ξ₁, …, ηₙ, ξₙ 线性无关：设 Σaᵢηᵢ + Σbᵢξᵢ = 0，两边作用 σ 得 Σbᵢηᵢ = 0，由 ηᵢ 无关得 bᵢ = 0，回代得 aᵢ = 0；共 2n 个向量故为 V 的基。\n6. 在此基下 σ(ηᵢ) = 0、σ(ξᵢ) = ηᵢ，按列向量约定 σ(εⱼ) = Σᵢ aᵢⱼ εᵢ 写出矩阵，恰为 n 个 J₂(0) 分块对角，即为所求 Jordan 形 A。\n\n**易错点**：\n- ξᵢ 的选取不唯一，但第 5 步的无关性论证对任意满足 σ(ξᵢ) = ηᵢ 的选取都成立，不要误以为要先证选取唯一。\n- 块内顺序必须是 (ηᵢ, ξᵢ)（η 在前）才得到超对角线为 1 的 J₂(0)；写成 (ξᵢ, ηᵢ) 会得到转置块，须说明仍在同一 Jordan 形约定下（或调整约定）。\n- 不能默认要扩域才有 Jordan 形：此处 m(x) | x² 在 Ω 上已完全分解；另外 n = 0 时 V = 0 结论平凡，n ≥ 1 时 σ ≠ 0，m(x) = x²。\n\n**不确定**：题干「存在…一个 Jordan 形矩阵 A」表述略松，实际结论是 A 唯一（除块排列外）= diag(J₂(0), …, J₂(0))，且 Ker σ = σ(V) 正是「极小多项式为 x²、幂零指数 2、秩为维数一半」这一情形的等价刻画；除此之外题干无歧义。
