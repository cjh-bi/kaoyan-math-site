2024 · 空间解析几何和高等代数 · 三1 | 证明 |20 分

设 A, B 均为实矩阵，证明：AᵀA + BᵀB 正定当且仅当 AX = 0 与 BX = 0 的公共解只有 0 解.
查看答案与解析
答案（证明思路提纲，非完整证明）
**要证**：记 M = AᵀA + BᵀB，则对任意 X 有 XᵀMX = ‖AX‖² + ‖BX‖² ≥ 0，故「M 正定」与「AX=0 与 BX=0 无非零公共解」是同一件事的两种说法。\n\n**用到的定理/引理**：\n- 实对称矩阵正定的定义：X≠0 ⟹ XᵀMX > 0\n- 二次型与向量范数的转化：Xᵀ(AᵀA)X = (AX)ᵀ(AX) = ‖AX‖² ≥ 0（即 AᵀA 半正定，两半正定阵之和仍半正定）\n- 实数域上非负数之和为零的等价性：‖AX‖² + ‖BX‖² = 0 ⟺ AX = 0 且 BX = 0\n- 分块矩阵视角（可选替代路线）：令 C = [A; B]，则 M = CᵀC，且 Ker C = Ker A ∩ Ker B，rank(CᵀC) = rank(C)\n- 正定 ⟹ 可逆（行列式 > 0），用于反向排除非零解\n\n**证明思路**：\n第 1 步（交代前提）：设 A 为 m×n、B 为 p×n 实矩阵，则 M = AᵀA + BᵀB 为 n 阶实对称矩阵，X ∈ Rⁿ，讨论正定性合法。\n第 2 步（写出二次型）：XᵀMX = XᵀAᵀAX + XᵀBᵀBX = ‖AX‖² + ‖BX‖² ≥ 0，得到 M 恒半正定。\n第 3 步（建立关键等价，全文枢纽）：XᵀMX = 0 ⟺ ‖AX‖² = ‖BX‖² = 0 ⟺ AX = 0 与 BX = 0 同时成立。\n第 4 步（必要性 ⟸）：若两方程组只有公共零解，则 X ≠ 0 时 X 不可能同时满足 AX=0、BX=0，由第 3 步知 XᵀMX ≠ 0，再结合第 2 步的非负性得 XᵀMX > 0，故 M 正定。\n第 5 步（充分性 ⟹）：反证。设 M 正定而存在 X₀ ≠ 0 使 AX₀ = 0、BX₀ = 0，则第 3 步给出 X₀ᵀMX₀ = 0，与正定性要求的 X₀ᵀMX₀ > 0 矛盾，故公共解只有 0。\n第 6 步（可选补充，一句话点出等价刻画）：等价地，C = [A; B] 列满秩，即 rank[A;B] = n，可作为同题的另一种表述。\n\n**易错点**：\n- 漏掉「M 是实对称阵」这一前提就直接谈正定；也要先说明 A、B 列数相同（否则 AᵀA + BᵀB 无意义）。\n- 第 4 步只写 XᵀMX ≠ 0 不够，必须先用第 2 步的非负性把 ≠0 升级为 >0；负数情形虽不可能，但逻辑上必须排除。\n- ‖AX‖² = 0 ⟺ AX = 0 依赖「实矩阵 + 标准内积」，若写成复矩阵须改用共轭转置且非负性不再平凡——不要照抄到复数域。\n- 别走 Sylvester 顺序主子式或 det(AᵀA+BᵀB) 的路线：A、B 是抽象矩阵，主子式无法计算，会陷入死路。\n\n**不确定**：题干只说「A, B 均为实矩阵」，未明说列数相同；此处按 A 为 m×n、B 为 p×n（同列数 n）理解，这也使「公共解」有意义。此外「正定」按 n 阶实对称矩阵的通常定义理解。
