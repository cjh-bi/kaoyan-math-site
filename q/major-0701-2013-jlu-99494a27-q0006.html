利用坐标旋转和平移将下面平面曲线方程化成标准形式，指出曲线类型：x² + 2y + y² + x + y + 1 = 0
查看答案与解析
答案（证明思路提纲，非完整证明）
**要证**：把方程经 45° 转轴消掉交叉项、再平移配方，化为 $X'^2 = -3/8$；标准形中不含 $Y'$，说明它是退化二次曲线，在实平面上无实轨迹（一对共轭虚平行直线），而不是抛物线也不是圆。\n\n**用到的定理/引理**：\n- 转轴公式 $x = X cos θ − Y sin θ, y = X sin θ + Y cos θ$，消交叉项条件 $cot 2θ = (A − C)/(2B)$\n- 二次曲线不变量判型：$δ = AC − B^2$（$δ = 0$ → 抛物线型，需另判退化）与三阶行列式 $Δ$（$Δ = 0$ → 退化）\n- 配方法 + 移轴公式 $X = X' + h, Y = Y' + k$（此处只沿 $X$ 方向平移，$Y$ 方向不动）\n- 二次曲线标准形分类表，含退化型（相交/平行/重合/共轭虚直线）的判读规则\n\n**证明思路**：\n1. 按 $Ax^2 + 2Bxy + Cy^2 + 2Dx + 2Ey + F$ 读出 $A = B = C = 1, D = E = 1/2, F = 1$，算得 $δ = AC − B^2 = 0$，属抛物线型，必须先转轴消 $xy$ 项。\n2. 由 $cot 2θ = (A − C)/(2B) = 0$ 取 $θ = 45°$，代入 $x = (X − Y)/√2, y = (X + Y)/√2$（即 $X = (x + y)/√2$）。\n3. 化简得 $2X^2 + √2 X + 1 = 0$：$Y$ 完全消失，说明曲线沿 $Y$ 方向平移不变，是一对平行于 $Y$ 轴的直线（实或虚）。\n4. 对 $X$ 配方：$2(X + √2/4)^2 + 3/4 = 0$，即 $(X + √2/4)^2 = −3/8$。\n5. 作平移 $X' = X + √2/4, Y' = Y$，写出标准形 $X'^2 = −3/8$（等价地 $2X'^2 + 3/4 = 0$）。\n6. 读结论：左端非负而右端为负，实平面内无轨迹点；辅以 $Δ = 0$（第一、二行相同）说明退化，定名为一对共轭虚平行直线。\n\n**易错点**：\n- $δ = 0$ 时不能用「离心率/椭圆双曲型」那套常规判型，也不能因为『既有旋转又有一次项』就写抛物线：$Y$ 不出现，化不出 $Y^2 = 2pX$，必须退回配方 + 判别式（$2 − 8 < 0$）下结论。\n- 旋转公式的方向不能写反：若误用 $x = (X + Y)/√2$，交叉项消不掉，后面全错；$Δ = 0$ 与 $δ = 0$ 建议各算一次作为交叉校验。\n- 平移只发生在 $X$ 方向，$Y$ 不平移也是合法刚体运动，但需在答卷上说明这不改变坐标系正交性与曲线类型。\n\n**不确定**：题面写作 $x^2 + 2y + y^2 + x + y + 1 = 0$。按字面理解无 $xy$ 项，只需配方得 $(x + 1/2)^2 + (y + 3/2)^2 = 3/2$，是一个实圆（半径 $√6/2$），此时题目要求的「坐标旋转」完全多余——与题干方法自相矛盾。故我按常见漏字版本（$2y$ 实为 $2xy$）给出提纲；另一可能是常数项或一次项符号与原卷不符（若一次项含 $Y$ 则为真抛物线）。定稿前须与原始 PDF 二次项核对。
