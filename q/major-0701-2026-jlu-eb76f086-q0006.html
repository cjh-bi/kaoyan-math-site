在空间直角坐标系下，求平面 Π : x + y + z = 2 内与直线 L : { x + 2y − 2 = 0 ; x + z − 1 = 0 } 垂直相交的直线的一般方程.
查看答案与解析
答案所求直线的一般方程为 { x + y + z − 2 = 0 ; 2x − y − 2z + 3 = 0 }（等价地：{ x + y + z = 2 ; 7x − 2y − 5z + 7 = 0 }，或对称式 x/(−1) = (y−1)/4 = (z−1)/(−3)）
1. 直线 $L$ 的方向 $\vec{s}=(1,2,0)\times(1,0,1)=(2,-1,-2)$，取点 $(2,0,-1)$，参数式 $(2+2t,\,-t,\,-1-2t)$。\n2. 代入 $\Pi$：$1-t=2\Rightarrow t=-1$，交点 $Q(0,1,1)$；因 $\vec{s}\cdot(1,1,1)=-1\neq0$，$L$ 与 $\Pi$ 只有一个交点，故所求直线必过 $Q$。\n3. 过 $Q$ 作垂直于 $L$ 的平面 $\Sigma:2x-y-2z+3=0$，则所求直线即 $\Pi\cap\Sigma$，其方向 $\vec{n}_\Pi\times\vec{n}_\Sigma=(-1,4,-3)$。\n4. 验证：$(-1,4,-3)\cdot(2,-1,-2)=0$（垂直），且两平面都含 $Q$（相交于 $L$），方向在 $\Pi$ 内（在平面内）。
