# 真题图片转录规范（2021 补充批次 · 「数学考研李扬」公众号）

你是数学考研真题转录员。任务：处理**若干篇文章**，每篇给出 msgid 与其真题图片路径列表
（LaTeX 排版的试卷页截图）。**每篇文章输出一个 JSON 文件**：`work/transcripts/<msgid>.json`（UTF-8，无 BOM）。

本批与 2025/2026 批的唯一差异：**msgid 形如 `2247504380-1`（含连字符）**，图片文件名形如
`work/imgs/2247504380-1_4.png`；JSON 里 `msgid` 字段照抄这个带连字符的 id，不要改动。

## 文章级 JSON Schema

```json
{
  "msgid": "2247504380-1",
  "exams": [
    {
      "school": "吉林大学",
      "year": "2021",
      "subject": "数学分析",
      "header_note": "15. 吉林大学 2021 年数学分析试卷",
      "source_imgs": ["work/imgs/2247504380-1_4.png"],
      "questions": [
        {
          "section": "一",
          "section_instruction": "填空题（每小题 5 分，共 30 分）",
          "no": "1",
          "score": 5,
          "form": "填空",
          "l1": "极限与连续",
          "l2": "函数极限计算",
          "stem": "求极限 $\\lim_{x\\to 0}\\dfrac{\\sin x - x}{x^3}$。"
        }
      ]
    }
  ]
}
```

- 一篇文章可能含 **1~4 张图**：可能是 数学分析+高等代数 两卷；可能**同一试卷跨两页图**（第二张图
  还是同样的标题或"（续）"、题目编号接着上一页）——**跨页的同一科试卷必须合并成一个 exam**，
  `source_imgs` 列出全部页；也可能是多校合发（如"北京交通大学 2021 年数学分析"），按图片标题拆成不同 exam。
- `school`/`year`/`subject` **一律以图片内的标题为准**（文章标题只是提示）。
- `header_note`：图片顶部标题原文。
- `section`：大题号，用中文数字 `一/二/三/四/五/六/七/八/九/十`。若卷面没有显式大题分组，按顺序每大题就是 `一`，小题号照抄。
- `section_instruction`：该大题的原始说明文字（如"计算题（每小题 10 分，共 60 分）"），没有则空字符串。
- `no`：大题内小题编号（"1","2",...）。卷面若是全卷连续编号（1..20），也按大题内重排为 1..n。
- `score`：该小题分值（数字）；卷面未标注则 `null`。
- `form`：`填空 | 计算 | 证明 | 判断 | 综合` 五选一（叙述/定义概念类 → 综合；解答+证明混合 → 综合）。
- `l1`/`l2`：知识点标签，**必须**从 `work/vocab.json` 中选：
  - `l1` 取自 `vocab.l1`；`l2` 必须与 `l1` 在 `vocab.l2`（{subject,l1,l2}）中成对出现。
  - 数学分析常用 l1：极限与连续/一元微分学/一元积分学/多元微分学/多元积分学/级数/广义积分与含参积分/常微分方程/解析几何
  - 高等代数常用 l1：多项式/矩阵与线性方程组/线性空间与线性变换/欧氏空间与二次型/解析几何/近世代数
  - 实在归类不了：`l1="未分类"`、`l2=""`。
- `stem`：题干全文。**标准 LaTeX**，行内公式用 `$...$`，独立成行的公式用 `$$...$$`；
  中文说明文字直接写；小题内分问用 `(1)…(2)…`，分问之间用 `\n` 换行；
  题干里包含本小题的全部信息（若大题有共享前提，把前提并入每一小题 stem 开头）。
  JSON 字符串里反斜杠要转义成 `\\`。
- 图片中看不清/缺字的部分：用 `【?】` 标记，不要瞎猜。整题无法辨认：跳过该题并在返回摘要中报告。

## 质量红线

1. 公式必须逐符号忠实转录，指数/分式/根号/积分限/矩阵结构不得出错；这是给学生刷题用的。
2. 不解题、不加答案。
3. 每道题都要有 l1（未分类除外也应给出最接近的）。
4. 写完后用 `node -e "JSON.parse(require('fs').readFileSync('<文件>','utf8'))"` 自检 JSON 合法。
