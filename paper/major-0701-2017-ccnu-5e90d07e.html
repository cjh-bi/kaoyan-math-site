（未标节）三 |2 个小问
设 $f(x)$ 在 $[a, b]$ 上连续.
(1) 证明: 若
$\int_{a}^{b} f(x) \mathrm{d}x = 0, \int_{a}^{b} x f(x) \mathrm{d}x = 0,$
则 $f$ 在 $(a, b)$ 内至少有两个零点.
(2) 证明: 若
$\int_{a}^{b} x^i f(x) \mathrm{d}x = 0, \ i = 0, \ 1, \ 2, \ \cdots, \ n \ (n \geqslant 1).$
则 $f$ 在 $(a, b)$ 内至少有 $n + 1$ 个零点.

$\frac{\partial^2 z}{\partial x^2} - y \frac{\partial^2 z}{\partial y^2} - \frac{1}{2} \frac{\partial z}{\partial y} = 0, \quad (*)$

$\begin{cases} u = x + a\sqrt{y}; \\ v = x + b\sqrt{y}. \end{cases} \quad (a \neq b)$

(2) 利用 (1) 的结果求方程 (*) 的通解.

（未标节）八 |2 个小问

$\frac{a_0^2}{2} + \sum_{n=1}^{+\infty} (a_n^2 + b_n^2) = \frac{1}{\pi} \int_{-\pi}^{\pi} f^2(x) dx.$
(1) 设 $f, \ g \in R[-\pi, \pi]$，$f$ 对应的 Fourier 级数为 $\dfrac{a_0}{2} + \displaystyle\sum_{n=1}^{+\infty} (a_n \cos nx + b_n \sin nx)$，$g$ 对应的 Fourier 级数为 $\dfrac{a_0}{2} + \displaystyle\sum_{n=1}^{\infty} (\alpha_n \cos nx + \beta_n \sin nx)$，利用 Parserval 等式证明：
$\frac{1}{\pi} \int_{-\pi}^{\pi} f(x) g(x) dx = \frac{a_0 \alpha_0}{2} + \sum_{n=1}^{\infty} (a_n \alpha_n + b_n \beta_n).$
(2) 利用 Parserval 等式证明：如果 $[-\pi, \pi]$ 上的连续函数 $f$ 和三角函数系
$\{1, \cos x, \sin x, \cdots, \cos nx, \sin nx, \cdots\}$
中每个函数正交，那么必有 $f(x) = 0$.
